# 经典布局模块 frame.js 功能实现

---

## 通用提示框接口

### 设计效果

在调用接口时左下角快速右滑出现一条长长的纯色提示框，最大长度为页面总长度的一半，超过该长度的文本换行。纯色提示框左侧边框被浏览器窗口边界遮挡，右侧边框有小圆角。然后关掉通知的“x”在框最左侧，然后周围有一圈进度条，刚弹出进度条是完整的圈包围着“x”，随时间推移包围角度逐渐减小，当减小至0度即这个圈退化成一个点时表示计时结束，一边淡化一边快速左滑移除。然后如果一个时刻有多个提示框，后来的提示框将叠在先来的上面，先来的计时结束移除后后来的向下滑动占据空出来的位置。提示框的堆叠有一个高度限制(这个高度限制为一个统一变量，后续可以添加设置功能。)，超过这个高度限制最底下的提示消息将被压出显示范围。

### 实现逻辑

`frontend/frame.js` 通过 `window.frame_show_notice()` 向功能模块提供通知接口，接收提示文字、显示时长、背景色、是否显示手动关闭按钮和文本颜色，返回带 `close()` 方法的冻结句柄。通知的队列、DOM 元素、倒计时及高度上限都保存在立即执行函数的闭包中，只将接口挂到 `window`，避免与其他模块的变量重名。调用示例：

```javascript
const notice = window.frame_show_notice(
    '视频正在准备，将采用缓冲播放。',
    6000,
    '#FFE69A',
    true,
    '#5C4300'
);
// 相关任务提前完成时，可主动关闭通知。
notice.close();
```

其中提示文字（`text` 参数）通过 `String()` 转换后赋给 `textContent`，保留文本换行，不解析 HTML。显示时长（`durationMs` 参数）以毫秒计，默认5000，设为0时持续显示，数值必须有限、非负且不超过2147483647。背景色（`backgroundColor` 参数）默认 `#FFFEFE`，文本颜色（`textColor` 参数）默认 `null`，显式颜色都由 `CSS.supports('color', value)` 校验；无效时长或颜色抛出 `TypeError`，页面尚无 `document.body` 时抛出调用错误，校验通过后才创建通知 DOM。文本颜色追加在第五个参数位置，原有四参数调用继续有效。

未传入文本颜色时，接口读取通知的计算背景色，对于可解析的 RGB 颜色且透明度不低于0.8的背景，以 `0.299R + 0.587G + 0.114B` 计算亮度，低于140使用白色，否则使用 `#202020`；其余情况保留 `#202020`。显式文本颜色直接覆盖自动选择的结果。关闭控件继承通知文字颜色，SVG 叉号和倒计时圆环使用 `currentColor`，因此随文本颜色一起变化。

关于通知容器，`ensureLayer()` 在第一次显示时把 `frame_notice_stack` 添加到 `document.body`。容器采用固定定位，贴住视口左侧、距底部12像素，宽度为 `50vw`，以较高层级覆盖当前页面，并通过 `overflow: hidden` 裁切超出范围的内容。容器本身不接收指针事件，通知卡片恢复接收，使通知之外的页面仍可操作。每条通知由定位行 `frame_notice_row` 和卡片 `frame_notice_card` 组成；卡片按内容取宽，最小宽度为240像素与可用宽度中的较小值，最大宽度不超过容器，使用 `overflow-wrap: anywhere` 让长文本和连续字符串换行。卡片左侧无圆角并贴住窗口边界，右侧圆角为6像素，文字使用15像素字号、1.3倍行高，上下内边距各6像素，左侧56像素内边距为关闭控件留出位置。

每条通知的左侧创建30×30像素控件。手动关闭按钮（`showCloseButton` 参数）默认显示，为 `button` 元素设置“关闭通知”的无障碍标签，点击后调用 `remove(item)`。传入 `false` 时使用不交互的 `span`，隐藏叉号并保留圆环。SVG 圆环半径为12，圆周长按 `2πr` 计算；圆环旋转到顶部起始，设置圆头描边和完整圆周的 `strokeDasharray`。显示时长大于0时，通过 Web Animations API 在线性时间内将 `strokeDashoffset` 从0增加到圆周长，使可见圆弧逐渐缩短，同时设置同等时长的定时器；时长为0时不创建定时器或圆环动画，完整圆环持续显示。

卡片创建后先设置 `translateX(-100%)`，加入队列、计算位置并读取一次布局，再设置 `translateX(0)`，以200毫秒向右滑入。倒计时结束时取消圆环动画，将虚线长度设为0并保留圆头，使圆环退化为一个点，然后进入关闭流程。手动关闭或调用返回句柄的 `close()` 时也进入同一流程：`remove(item)` 先用 `closed` 标记避免重复关闭，清除定时器并暂停尚在执行的圆环动画，将透明度降为0、向左平移100%，关闭指针交互；200毫秒后才从 DOM 和队列中移除并取消残余动画。

关于堆叠，队列通过 `notices.unshift(item)` 把新通知放在最前面，`layout()` 按最新到最旧的顺序测量卡片实际高度，以8像素间距累积位置。容器高度取总内容高度、统一变量 `noticeStackMaxHeight` 和视口高度减24像素中的最小值，当前上限为320像素；旧通知位于底部，超出范围时仅被裁切，仍保留在队列并继续倒计时。卡片从队列移除后重新布局，其上方通知通过 `bottom` 的200毫秒过渡向下占据空位。被裁切的通知在剩余空间足够且尚未到期时也可重新显示。

窗口大小变化时调用 `scheduleLayout()`，浏览器支持 `ResizeObserver` 时还监听卡片尺寸变化，将多次布局请求合并到一个动画帧，处理宽度变化、文字重新换行后的高度调整。最后一条通知移除后，关闭流程取消待执行的布局帧、断开尺寸观察器、移除窗口监听和通知容器；下一次调用时重新创建。接口只管理当前页面内的通知状态，不写入配置或元数据文件，高度上限目前没有对外设置接口。
