# 问题分析与解决方案

## 问题原因

在IDE中直接运行不能成功读取`./config/basedir.txt`的原因是：

1. **工作目录差异**：
   - 当在沙箱中运行时，沙箱会自动切换到脚本所在目录（backend目录）
   - 当在IDE中运行时，IDE可能会在项目根目录启动脚本，而不是backend目录
   - 原始代码使用相对路径`./config/basedir.txt`，在不同工作目录下会解析到不同位置

2. **路径解析问题**：
   - 在backend目录运行时：`./config/basedir.txt` 解析为 `backend/config/basedir.txt`（正确）
   - 在项目根目录运行时：`./config/basedir.txt` 解析为 `config/basedir.txt`（不存在）

## 解决方案

修改了`back.py`文件，使用基于脚本自身位置的绝对路径来定位配置文件：

```python
# 获取脚本所在目录的绝对路径
script_dir = os.path.dirname(os.path.abspath(__file__))

nowpath = './'
# 使用相对于脚本目录的路径来定位config文件
basedir_path = os.path.join(script_dir, 'config', 'basedir.txt')
if os.path.exists(basedir_path) and os.path.isfile(basedir_path):
    with open(basedir_path,'r',encoding='utf-8') as basedir_file:
        nowpath = basedir_file.read().strip()
```

2. **解决深度问题**：

## 问题原因

1. **布局冲突**：
   - `.treemap` 元素同时使用了 `position: absolute` 和 `flex: 1`，这两个属性是冲突的
   - 硬编码的宽度 `width: calc(100% - 142px)` 导致宽度计算错误
   - 菜单栏没有设置 `flex-shrink: 0`，可能会被压缩

2. **DOM 操作问题**：
   - `processDirectoryStructure` 函数使用 `container.innerHTML = ''` 清空整个容器，包括菜单栏
   - 每次绘制树状图时都会重新创建菜单栏，导致菜单消失

1. **修改 CSS 样式**：
   - 将 `.treemap` 的 `position` 从 `absolute` 改为 `relative`，使其遵循 flex 布局
   - 移除 `.treemap` 的硬编码宽度，让它通过 `flex: 1` 自动填充剩余空间
   - 为 `.treemap` 添加 `min-width: 100px`，确保即使在小窗口下也能显示
   - 为 `.treemap-menu` 添加 `flex-shrink: 0`，确保它不会被压缩

2. **修改 DOM 操作**：
   - 不再使用 `container.innerHTML = ''` 清空整个容器
   - 而是只移除 `.loading` 元素和旧的 `.treemap` 元素
   - 使用 `container.insertBefore(mapDiv, container.querySelector('.treemap-menu'))` 在菜单栏前面添加新的树状图容器

## 技术原理

- **Flex 布局**：使用 `display: flex` 让 `.treemap` 和 `.treemap-menu` 并排显示
- **Flex 属性**：

  - `.treemap-menu` 的 `flex-shrink: 0` 确保它不会被压缩
