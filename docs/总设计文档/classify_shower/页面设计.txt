—————————— 番剧小版块设计描述 ——————————

在点击番剧小版块时进入番剧页面，番剧页面左侧有一个侧边栏（粉蓝色吧），中右侧是主展示区，主展示区中靠近顶部的位置有一个搜索框，右侧有搜索按钮，框的下面是用作海报展示区的大div,其中两行5列有10个展示框，也就是一次展示10部番剧，每部番剧的海报放在这个番剧展示框里，海报下面是番剧名称(较大字体)，名称下面是年份和标签(较小字体)，如果标签很多，那么溢出部分就变成省略号。保持大div的高度不会过高以至于出现滚动条。然后海报展示区下面是分页框，标识当前的页码和总页码，例如现在在第一页，分页框里“1 2 3 ... 55 下一页”里“1”所在的方框用彩色强调，点击“下一页”按钮或对应页码海报展示区就会换页，展示那一页的10部番剧。

关于侧边栏，从上到下依次有“排序方式”、“按标签筛选”的功能，“排序方式”后面是选择框，其中的选项有“按年份”、“按入库时间”、“按拼音首字母”。“按标签筛选”右边是勾选框，下边是输入框，输入框按钮上文字是"OK",点击即应用标签筛选。输入框按钮右侧还有一个按钮，其上文字“选择标签”，点击“选择标签”按钮在侧边栏右侧滑出一个大的菜单框，这个大菜单框里显示所有番剧上可能带有的所有标签(以拼音首字母排序，像查字典一样，"A"下面就是拼音首字母为a的那些标签)，每个标签右侧都是勾选框。这些标签都装在一个可以出现上下滚动条的div里。在菜单框右上角有“正选/反选”两个模式的切换按钮，点击切换模式，正选模式是这些标签勾选哪个就是哪些标签，反选模式是选择没有被勾选的那些标签。在底部有“确定”按钮，点击“确定”这个大菜单框收起，并相应刷新输入框里的文字，输入框内不同标签间用","间隔。这个输入框和“选择标签”按钮当且仅当“按标签筛选”被勾选时才会被激活，若未勾选则变成灰色不可点击。侧边栏底部有按钮“刷新数据库”。

与后端交互：
在进入番剧页面时，前端向后端发送此时采用的排序方式并请求第一页的那10部番剧的数据和番剧总数以及页面数。然后根据返回的数据来填充海报<img>的src以及其他信息。在换页的时候就向后端请求那一页的番剧信息，也就是说不会一次性发送所有的番剧信息。侧边栏里，在“排序方式”选项更改时，要向后端发送选择的排序方式并重新请求这一页的番剧信息，海报展示区内容清空并显示加载中，番剧信息返回后重新显示内容。“按标签筛选”勾选状态发生改变、输入框“OK”按钮被点击、“选择标签”弹出的大菜单框里“确定”按钮被点击时，也要立刻通知后端并重新请求番剧信息。侧边栏底部的“刷新数据库”按钮点击时，向后端发送命令，后端重新扫描目录并执行数据库重建，重建期间海报展示区内容清空并显示数据库重建中，重建完成后重新显示内容。

番剧详情页设计：
对于每一个海报添加点击监听函数，跳转至详情页(使用new_page())，然后详情页的居中靠左的区域放置海报图片，靠右区域从上到下依次是番剧名称、时间和全部标签、番剧简介、简介来源、是否有弹幕以及弹幕来源、剧集。
这些信息需要后端从番剧目录下去读取。从__MD__.json里读取番剧名称("name")、时间("year"和"month")和全部标签("item")、番剧简介("introduction")、简介来源("introduction-src")，其中"year"和"month"可能没有(如果没有就显示未知时间信息)，"introduction"也可能没有(如果没有就显示“无简介”)，"introduction-src"可能没有(如果没有就不显示来源信息)，"introduction-src"的结构如下例：
    "introduction-src":
    {
        "src-name":"维基百科",
        "src-url":""
    },......
关于弹幕，对每一个视频例如文件名称是xxx.mp4，后端需要验证 xxx.files/dm.js 文件是否存在，番剧目录下但凡有一个视频检测到 xxx.files/dm.js 存在，那么就认为“有弹幕”，否则就是“无弹幕”。然后关于弹幕来源需要后端遍历所有视频文件的 xxx.files/dm-info.json（部分视频可能并不存在此路径），这个json里可能有键“dm-src”内容形如：
"dm-src":
    [
        {
            "name":"B站",
            "url":"",
            "update-time":1777367401
        }
    ]
将找到的所有不同来源每个以标签形式显示在详情页上。

关于剧集，默认将番剧目录下所有视频按文件名称排序(升序)，然后第一个就是“第1集”，第二个就是“第2集”，以此类推。有可能有的剧集有弹幕，有的剧集没有弹幕，有弹幕的剧集按钮要与没有弹幕的外观作出区分。
如果__MD__.json 里 "episode-map" 键存在有值，那么根据其值来确定剧集按钮。其值形如：
    "episode-map":
    [
        {"order":1,"path":"[Airota][Fumetsu no Anata e S2][01][BDRip 1080p AVC AAC][CHS].mp4","name":"轮回的执着"}
    ]
这表示该番剧有1集，第1集对应文件"[Airota][Fumetsu no Anata e S2][01][BDRip 1080p AVC AAC][CHS].mp4"，名称叫"轮回的执着"。剧集按钮既要显示这是第几集，还要显示这一集叫什么名字。当然如果__MD__.json 里没有"episode-map" 键就按默认文件名称排序的方法来，这种情况每一集没有名字。
