数据库设计

1.番剧

分类标准：如果一个文件夹下有__MD__.json，读取后其中的“type”对应的值为“番剧”，例如：

{
"type":"番剧",
"name":"回复术士的重启人生",
"names":["棍勇","棍之勇者成名录"],
"cover":"./cover.webp",
"item":["猎奇","16+","暗黑"],
"introduction":"《回复术士的重启人生》（日语：回復術士のやり直し）是日本作家月夜泪在成为小说家吧上连载的网络小说，以及其后由KADOKAWA的角川Sneaker文库出版的轻小说。故事讲述拥有治愈能力、但遭冒险队伍凌辱虐待的少年少年凯亚尔，因缘际会返回成为【愈】之勇者前的时间点，向曾经加害自己与亲友的仇人复仇的经历。",
"introduction-src":
{
"src-name":"维基百科",
"src-url":" https://zh.wikipedia.org/wiki/%E5%9B%9E%E5%BE%A9%E8%A1%93%E5%A3%AB%E7%9A%84%E9%87%8D%E5%95%9F%E4%BA%BA%E7%94%9F "
},
"year":2021
"entry-time":12345678
}

那么该文件夹是一部“番剧”，将这个文件夹的根目录、番剧的名字、年份、标签与封面图地址("cover"的内容)、入库时间戳这六条数据入数据库。
如果某文件夹是一部“番剧”，那么该文件夹下默认所有的视频文件为该番剧的剧集。除了那五条数据，剧集的数量也被加入到数据库里。

关于自定义分类功能

在视频、图片、音频等等这些板块里，除了原有的中类(例如"二次元相关")、小类(例如在"二次元相关"下有小类"番剧")以外，用户还可以自行预定义一些种类，下面以视频板块下添加中类"知识星球"为例来说明如何实现这一点。

首先编辑 config/classify_shower_config.json，找到其中"custom_class"键对应值。我们要改的是视频板块的分类，因此要更改其中"video"里的内容，更改为如下这样：

    "custom_class":
    {
        "video":
        {
            "知识星球":
            [
                {"name":"视频课程"}
                
            ]
        },
        "picture":
        {

        }
    }
