# 全局配置文件说明

仓鼠存储管理器-TIPHERETH 全局配置文件在 `backend\config\global_config.json`。本文档将详细说明该文件的内容。

***

## 概览

一份完整的 TIPHERETH 版本全局配置文件 `global_config.json` 的内容示例如下：

```json
{
    "base_dir": [
        "X:\\资源"
    ],
    "base-port": 8768,
    "http-url-config": {
        "max-blob-bytes": 104857600,
        "tmp-blob-file": false
    },
    "connect_timeout": 1200
}
```

## base_dir：工作目录

`base_dir` 是 TIPHERETH 存储管理器所管理资源的根目录列表。比如我有一部分资源放在 `X:\资源` 目录下，另一部分资源放在 `Y:\我的资源` 目录下，我希望 TIPHERETH 存储管理器能够同时管理这两部分资源，那么我就可以在 `base_dir` 中添加 `X:\资源` 和 `Y:\资源`：

```json
"base_dir": [
    "X:\\资源",
    "Y:\\我的资源"
]
```
