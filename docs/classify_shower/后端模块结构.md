# 分类展示后端模块结构

`backend/classify_shower_back.py` 保留 `ClassifyShowerModule` 和模块工厂 `create_module()`，负责分类配置、拼音、番剧数据库扫描、列表与详情查询，以及主消息入口。

`backend/classify_shower_video.py` 集中实现视频播放与评论功能：

- `ClassifyShowerVideo`：视频元数据和 H265 兼容来源、FFmpeg 流任务、时间戳修复、关键帧与探测缓存、弹幕、观看记录、评论来源管理及评论页面响应。视频任务、缓存和评论连接均由该组件实例持有。
- 评论数据库连接管理、分页查询、资源路径转换和 HTML 渲染辅助函数。
- FFmpeg 检查、下载及 `settings()` 安装向导；这些安装入口仍由原后端模块导出。

`ClassifyShowerModule` 使用组合方式，在 `init_components()` 中创建 `self.video`，并加入 `self.components`。组件构造函数显式接收 `global_config`、`script_dir`、配置读取回调 `get_config` 和保存回调 `save_config`。读取回调使组件在主模块重新加载配置后仍能使用当前配置。视频模块不导入主模块。

主模块中的 `ClassifyShowerComponent` 协议声明统一接口，具体组件无需继承它：

- `handle_message(websocket, data) -> bool`：已处理命令返回 `True`；不识别的命令返回 `False`。
- `when_connect(websocket)`、`when_disconnect(websocket)`：连接生命周期。
- `shutdown()`：释放组件持有的任务、进程及数据库连接。

主消息入口按 `components` 的顺序分发，首个返回 `True` 的组件终止分发；所有组件均未处理时，进入分类浏览逻辑。连接建立、断开及退出时，主模块依次调用每个组件的生命周期方法，最后关闭番剧数据库。

后续实现 `classify_shower_picture.py`、`classify_shower_audio.py` 时，各自实现上述异步接口，在 `init_components()` 中创建实例并加入 `components` 即可。组件内部的方法和状态保留在各自实例中，不需要修改主模块的继承关系或添加业务方法转发。

前后端命令名、响应字段保持不变。内部视频业务方法通过 `module.video` 访问，例如 `module.video.start_video_stream()`。视频和评论辅助函数的导入位置为 `classify_shower_video`。发布清单 `build/filelist.txt` 同时包含两个模块，新增组件也需要加入该清单。
