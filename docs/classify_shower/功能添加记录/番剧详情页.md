# 番剧详情页

前端类名：CS\_AnimeDetailWidget

***

## 页面设计

番剧详情页设计：
对于每一个海报添加点击监听函数，跳转至详情页(使用`new_page()`)，然后详情页的居中靠左的区域放置海报图片，靠右区域从上到下依次是番剧名称、时间和全部标签、番剧简介、简介来源、是否有弹幕以及弹幕来源、剧集。

这些信息需要后端从番剧目录下去读取。从`__MD__.json`里读取番剧名称("name")、时间("year"和"month")和全部标签("item")、番剧简介("introduction")、简介来源("introduction-src")，其中"year"和"month"可能没有(如果没有就显示未知时间信息)，"introduction"也可能没有(如果没有就显示“无简介”)，"introduction-src"可能没有(如果没有就不显示来源信息)，"introduction-src"的结构如下例：

```json
"introduction-src":
{
    "src-name":"维基百科",
    "src-url":""
},......
```

剧集元数据目录使用 `<完整视频文件名（含扩展名）>@meta/` 命名，与视频位于同一目录；例如 `xxx.mp4` 和 `xxx.ts` 分别对应 `xxx.mp4@meta/` 和 `xxx.ts@meta/`。

关于弹幕，对每一个视频例如文件名称是xxx.mp4，后端需要验证 xxx.mp4@meta/rmcf.json 文件是否存在(这个文件记录了每个弹幕源的时间重映射配置)，番剧目录下但凡有一个视频检测到 xxx.mp4@meta/rmcf.json 存在，那么就认为“有弹幕”，否则就是“无弹幕”。然后关于弹幕来源需要后端遍历所有视频文件的 xxx.mp4@meta/dm-info.json（部分视频可能并不存在此路径），这个json里可能有键“dm-src”内容形如：

```json
"dm-src":
[
    {
        "name":"B站",
        "url":"",
        "update-time":1777367401
    }
]
```

将找到的所有不同来源每个以标签形式显示在详情页上。

关于剧集，默认将番剧目录下所有视频按文件名称排序(升序)，然后第一个就是“第1集”，第二个就是“第2集”，以此类推。有可能有的剧集有弹幕，有的剧集没有弹幕，有弹幕的剧集按钮要与没有弹幕的外观作出区分。

如果`__MD__.json` 里 "episode-map" 键存在有值，那么根据其值来确定剧集按钮。其值形如：

```json
"episode-map":
[
{"order":1,"path":"[Airota][Fumetsu no Anata e S2][01][BDRip 1080p AVC AAC][CHS].mp4","name":"轮回的执着"}
]
```

这表示该番剧有1集，第1集对应文件"\[Airota]\[Fumetsu no Anata e S2]\[01]\[BDRip 1080p AVC AAC]\[CHS].mp4"，名称叫"轮回的执着"。剧集按钮既要显示这是第几集，还要显示这一集叫什么名字。当然如果\_\_MD\_\_.json 里没有"episode-map" 键就按默认文件名称排序的方法来，这种情况每一集没有名字。

## 编辑标签功能

`classify_shower_video.js 1017-1025` 这里的`tagsdiv`里除了添加`uniqueTags`里的内容外，在后面再加上一个内容为“添加标签”的特殊tag。这个特殊tag样式在 `classify_shower_video.js 1022-1022` 基础上将背景颜色改为蓝色#1976d2，然后在“添加标签”文本前加上一个大“+”号。

这个标签是一个按钮，鼠标移动到其上时会略微变大。

另外实现一个弹出窗口的工具函数 `cs_createPopupWindow` 在 `classify_shower.js` 里，弹出窗口的方式风格与 `classify_shower_video.js 577-688` 这里实现的一样，返回弹出的这个窗口的div(函数执行完窗口还没有弹出)，这个div里定义成员函数`popMe()`和`killMe()`,使用时在返回的这个空白div里添加内容，然后调用`div.popMe()`弹出窗口，然后执行完成操作就调用`div.killMe()`来消除窗口。这个工具函数在之后的功能实现里会多次用到。
