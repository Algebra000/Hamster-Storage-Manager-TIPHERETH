# 弹幕资源批量更新工具

---

## srcURL-build.py

用于根据网址构建弹幕URL源文件：`dm-srcURL.json`。

### 视频文件弹幕数据结构

视频文件的弹幕数据和评论相关元数据保存在视频同级的 `<完整视频文件名（含扩展名）>@meta/` 文件夹中。例如，`xxx.mp4` 对应 `xxx.mp4@meta/`，`xxx.ts` 对应 `xxx.ts@meta/`。
`dm-srcURL.json` 生成后可以将其拖入`<完整视频文件名（含扩展名）>@meta/`文件夹中，之后使用`srcURL-downloader.py` 下载弹幕资源并构建弹幕数据，这样在使用 classify_shower 播放视频的时候就能见到弹幕了。

```
├── xxx.mp4@meta/
│   ├── __RECORD__.json  (保存视频上次观看进度的文件)
│   ├── dm-srcURL.json   (弹幕URL源文件)
│   ......
│   (之后的文件夹和文件都可以由 dm-srcURL.json 生成)
│   ......
└── xxx.mp4
```

一个构建完成的、有效的有弹幕视频的文件夹结构示例如下：

```
├── xxx.mp4@meta/
│   ├── __RECORD__.json  (保存视频上次观看进度的文件)
│   ├── dm-srcURL.json   (弹幕URL源文件)
│   ├── raw/             (原始弹幕数据文件夹)
│   │   ├── dm1.json     (来源1第1次获取到的原始弹幕数据)
│   │   ├── dm1-2.json   (来源1第2次获取到的原始弹幕数据)
│   │   ......
│   │   ├── dm1-x.json   (来源1第x次获取到的原始弹幕数据)
│   │   ├── dm2.json     (来源2第1次获取到的原始弹幕数据)
│   │   ├── dm2-2.json   (来源2第2次获取到的原始弹幕数据)
│   │   ......
│   │   └── dmy-x.json   (来源y第x次获取到的原始弹幕数据)
│   │  (该文件夹保存了每一次更新时每个来来源的原始弹幕数据)
│   │  (如果太大可以删掉该文件夹，下次更新自动建立)
│   │  
│   ├── dm-info.json     (所有弹幕源的汇总弹幕信息文件)
│   ├── rmcf.json        (每个弹幕源的时间重映射数据文件)
│   ├── dm1.json         (来源1的最终弹幕数据文件)
│   ......       
│   ├── dmy.json        
│   ├── dma123.json      (b站以外来源的弹幕数据，用户手动加入)   
│   ├── dmb456.json      (b站以外来源的弹幕数据，用户手动加入)
│   ......        
│   ├── dmb456.json      (b站以外来源的弹幕数据，用户手动加入)
│   ......               (评论之类的其他元数据)
│   
└── xxx.mp4
```
