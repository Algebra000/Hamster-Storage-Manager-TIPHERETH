# 番剧详情页

前端类名：CS\_AnimeDetailWidget，遵循[页面标准](../../模块化设计思路.md#关于功能模块的页面标准)。

***

## 页面设计

番剧详情页设计：
对于每一个海报添加点击监听函数，跳转至详情页(使用`new_page()`)，然后详情页的居中靠左的区域放置海报图片，靠右区域从上到下依次是番剧名称、时间和全部标签、番剧简介、简介来源、是否有弹幕以及弹幕来源、剧集。这些内容全部放在一个居中的无边框白色半透明圆角div容器(该节后续将这个容器称作详情页主容器，不再赘述)里，这个容器的滚动条经过 cs_beautifyScrollbar 函数美化。

这些信息需要后端从番剧目录下去读取。从`__MD__.json`里读取番剧名称("name")、时间("year"和"month")和全部标签("item")、番剧简介("introduction")、简介来源("introduction-src")，其中"year"和"month"可能没有(如果没有就显示未知时间信息)，"introduction"也可能没有(如果没有就显示“无简介”)，"introduction-src"可能没有(如果没有就不显示来源信息)，"introduction-src"的结构如下例：

```json
"introduction-src":
{
    "src-name":"维基百科",
    "src-url":""
},......
```

剧集元数据目录使用 `<完整视频文件名（含扩展名）>@meta/` 命名，与视频位于同一目录；例如 `xxx.mp4` 和 `xxx.ts` 分别对应 `xxx.mp4@meta/` 和 `xxx.ts@meta/`。

关于弹幕，对每一个视频例如文件名称是xxx.mp4，后端需要验证 xxx.mp4@meta/rmcf.json 文件是否存在(这个文件记录了每个弹幕源的时间重映射配置)，番剧目录下但凡有一个视频检测到 xxx.mp4@meta/rmcf.json 存在，那么就认为“有弹幕”，否则就是“无弹幕”。然后关于弹幕来源需要后端遍历所有视频文件的 xxx.mp4@meta/dm-info.json（部分视频可能并不存在此路径），这个json里可能有键“dm-src”内容形如：

```json
"dm-src":
[
    {
        "name":"B站",
        "url":"",
        "update-time":1777367401
    }
]
```

将找到的所有不同来源每个以标签形式显示在详情页上。

关于剧集，默认将番剧目录下所有视频按文件名称排序(升序)，然后第一个就是“第1集”，第二个就是“第2集”，以此类推。有可能有的剧集有弹幕，有的剧集没有弹幕，有弹幕的剧集按钮要与没有弹幕的外观作出区分。

如果`__MD__.json` 里 "enable-episode-map" 键存在有值且为 true 或不存在，则读取 "episode-map" 键。若 "episode-map" 键存在有值，那么根据其值来确定剧集按钮。其值形如：

```json
"episode-map":
[
{"order":1,"path":"[Airota][Fumetsu no Anata e S2][01][BDRip 1080p AVC AAC][CHS].mp4","name":"轮回的执着"}
]
```

这表示该番剧有1集，第1集对应文件"\[Airota]\[Fumetsu no Anata e S2]\[01]\[BDRip 1080p AVC AAC]\[CHS].mp4"，名称叫"轮回的执着"。剧集按钮既要显示这是第几集，还要显示这一集叫什么名字。当然如果\_\_MD\_\_.json 里没有"episode-map" 键就按默认文件名称排序的方法来，这种情况每一集没有名字。

## 编辑按钮

编辑按钮位于半透明白色详情页主容器右上角，点击后跳转到编辑页面，编辑页面用于编辑番剧的各种基本信息。编辑页面不使用 `new_page` 函数，而是直接将当前页面上详情页主容器中现有的内容隐藏，然后在容器里添加编辑页面的内容。

如果以“[]”代指输入框，“<>”代指按钮，“=”代指开关，编辑页面的内容大体上是：

```
番剧名称 [ ]
放送时间 [ ]年[ ]月 <选择时间>

简介 
[                                     ]
简介来源
名称 [ ] URL [ ]

剧集映射 =

<放弃更改并返回详情页> <保存并返回详情页> 
```

关于 “选择时间” 按钮，点击后打开下拉框，其中为日期选择器，用户在其中选择日期后将日期显示在前面的输入框里。

关于简介来源，其下的“名称”和“URL”输入框与“简介来源”标签都放在一个边框里。

关于剧集映射，其开关对应`__MD__.json` 里 "enable-episode-map" 键的值。打开后"enable-episode-map" 键设为 true (如果不存在则创建该字段)，同时下方会显示出详细的编辑UI，如果“【】”代指列表，那么大概的UI布局：
```
剧集映射 =
<设为默认> <+>
【】
```
其中列表里各项之间从上到下排列。将番剧目录下每一个视频文件对应列表里的一个项，每一项从左到右依次是文件名称文本标签、“第X集”文本标签、“剧集名称[]”输入框、“使用该视频”勾选框，这些项按照集序数从上到下升序排列。如果“使用该视频”勾选框未被选中，那么就将该项“第X集”文本标签和“剧集名称[]”输入框都替换为灰色的“-”文本标签，并且将文件名称文本标签字体变为灰色。

如果`__MD__.json` 里 "episode-map" 键存在有值，那么根据其值来确定列表里每一项的内容，值(是一个json列表)里未提到的视频文件，就默认按文件名称排序后，将“使用该视频”勾选框设为未选中状态排列在列表的末尾。如果"episode-map" 键不存在，那么就默认按文件名称排序来决定集序数，然后剧集名称空着，将“使用该视频”勾选框全部设为选中状态。

当鼠标停留在这些项上时，项的右侧展开一小窗口，小窗口里有上下小三角按钮，分别有将项次序上移一位、下移一位的功能，还有一个“设为第[]集”的输入框与对应的确定按钮，按下确定按钮如果输入合法则将该项移动到对应位置，否则红字提示不合法。项的位置变动时“第X集”的标签以及集序号也应同样变动。

剧集列表里除了与每一个视频文件对应的项，还允许有不严格要求与视频文件对应的项，即候补剧集。候补剧集项从左到右依次是可编辑文件名称文本标签、“第X集”文本标签、“剧集名称[]”输入框、红底白字“删除”按钮，其他与视频文件对应的剧集项相同。可编辑文件名称文本标签点击后会转化为输入框以供用户编辑。如果`__MD__.json` 里 "episode-map" 列表里如果有一项指向的视频文件不存在而且不可访问或者干脆为空，其将作为候补剧集项显示在编辑页面的剧集列表里。

点击“设为默认”按钮，则将列表里的每一项的剧集名称都设为空。并重置集序数顺序为默认的按文件名称排序，将“使用该视频”勾选框全部设为选中状态，并清除所有候补剧集项。

“+”按钮为一个圆形按钮，鼠标移至其上其title属性为“添加候补剧集”。点击“+”按钮，则在列表末尾添加一个空的候补剧集项，可编辑文件名称文本标签的初始内容为“在此键入文件名称”。

这个列表的滚动条经过 cs_beautifyScrollbar 函数美化。

点击“保存并返回详情页”按钮，则向后端发送 `CS_SET_ANIME_DETAIL` 消息，将当前编辑页面的内容保存到 `__MD__.json` 里，然后从当前页面上详情页主容器中移除编辑页面的内容，显示详情页的内容；而点击“放弃更改并返回详情页”按钮后，直接移除编辑页面的内容，显示出详情页的内容。

进入编辑页面时，所有输入框的初始内容与进入编辑页面前详情页上的内容一致；返回详情页时，详情页上的内容将同步更新。

## 编辑标签功能

`classify_shower_video.js 1017-1025` 这里的`tagsdiv`里除了添加`uniqueTags`里的内容外，在后面再加上一个内容为“添加标签”的特殊tag。这个特殊tag样式在 `classify_shower_video.js 1022-1022` 基础上将背景颜色改为蓝色#1976d2，然后在“添加标签”文本前加上一个大“+”号。

这个标签是一个按钮，鼠标移动到其上时会略微变大。

另外实现一个弹出窗口的工具函数 `cs_createPopupWindow` 在 `classify_shower.js` 里，弹出窗口的方式风格与 `classify_shower_video.js 577-688` 这里实现的一样，返回弹出的这个窗口的div(函数执行完窗口还没有弹出)，这个div里定义成员函数`popMe()`和`killMe()`,使用时在返回的这个空白div里添加内容，然后调用`div.popMe()`弹出窗口，然后执行完成操作就调用`div.killMe()`来消除窗口。这个工具函数在之后的功能实现里会多次用到。
